### Task 2: Admin API — BU CRUD (cycle-safe), lead times, coverage scope
**Files:** `app/api/admin_business_units.py`, `app/api/admin_lead_times.py`, `app/api/admin_settings.py`, register in main, `tests/test_admin_bu.py`, `tests/test_admin_lead_times.py`, `tests/test_admin_scope.py`
**Contracts:** per spec §API Administration. Cycle detection walks the parent chain of the proposed parent; self-parent and descendant-parent → 422. DELETE with children or customers → 409. Lead-times GET returns all rows + effective-resolution helper is NOT built here (engine work, stage 5). Coverage scope PUT validates against enums (Planned/Budgeted/Confirmed; Primary/Contingency), rejects unknown values 422, empty arrays 422.
**Required tests:** cycle 422 (self, grandchild), delete-with-children 409, delete-with-customers 409, happy CRUD; lead-times upsert replaces; scope roundtrip + validation 422s.

### Task 3: Admin API — substitutions + safety stocks
**Files:** `app/api/admin_substitutions.py`, `app/api/admin_safety_stocks.py`, register, `tests/test_admin_substitutions.py`, `tests/test_admin_safety_stocks.py`
**Contracts:** per spec. Substitution POST with from==to → 422; duplicate direction → 409; customer-rules PUT upserts per (customer, substitution). Safety stocks PUT: rows with quantity null → delete row; 0 → keep explicit-zero row; GET distinguishes unset (absent) from zero (present).
**Required tests:** the null≠0 invariant both directions; from≠to; duplicate 409; customer rule unique upsert.

### Task 4: Company inventory API (read + C-03R maintenance)
**Files:** `app/api/company_inventory.py`, register, `tests/test_company_inventory.py`
**Contracts:** GET returns {on_hand, assignments, on_order}; every row carries unit; on_order undated rows keep expected_date null. Maintenance POST/PATCH/DELETE on on-hand rows; row with source_system=="oracle" → 409 with reason; code carries COMPROMISE[C-03R] marker comment.
**Required tests:** GET shape incl. undated on_order; maintenance CRUD happy path; oracle-row 409; unit always present.

### Task 5: Customer-owned API (status, template, upload)
**Files:** `app/api/customer_owned.py`, register, `tests/test_customer_owned.py`
**Contracts:** GET per spec (has_uploaded honesty). Template: openpyxl workbook, header row Product/Quantity/Unit. Upload: parse xlsx, validate (unknown product name, bad unit, negative qty → 422 listing row numbers), replace positions atomically, append uploads row. Other customers' data untouched.
**Required tests:** has_uploaded false→true transition; empty-but-uploaded (has_uploaded true, positions []); replace semantics; validation 422 with row numbers; template downloads and re-uploads round-trip (write cells with openpyxl in the test); isolation between customers.
